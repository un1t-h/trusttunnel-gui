# TrustTunnel GUI

Графический VPN-клиент для Windows под протокол [TrustTunnel](https://trusttunnel.org/): одна кнопка «Подключить», серверы карточками, живая статистика, тёмная и светлая тема.

TrustTunnel — открытый VPN-протокол от AdGuard. Он работает поверх HTTPS (HTTP/2 или HTTP/3), поэтому трафик похож на обычный веб и хорошо проходит через DPI.
Само соединение устанавливает официальный [`trusttunnel_client`](https://github.com/TrustTunnel/TrustTunnelClient), а программа даёт ему удобный интерфейс.

![Главное окно](docs/main-dark.png)

## Установка

Откройте **PowerShell** и выполните:

```powershell
irm https://raw.githubusercontent.com/un1t-h/trusttunnel-gui/main/install.ps1 | iex
```

Скрипт скачает последнюю версию, положит её в `%LOCALAPPDATA%\Programs\TrustTunnelGUI` и создаст ярлыки «TrustTunnel» в меню «Пуск» и на рабочем столе.
Повторный запуск той же команды обновляет программу.

Можно и вручную: скачайте `TrustTunnelGUI.exe` со страницы [Releases](https://github.com/un1t-h/trusttunnel-gui/releases/latest) и запустите.
Устанавливать ничего не нужно, хватит Windows 10/11 со встроенным .NET Framework 4.8.

## Первый запуск

1. Запустите TrustTunnel. Windows попросит права администратора: без них нельзя создать VPN-адаптер.
2. Программа предложит скачать официальный клиент TrustTunnel (`trusttunnel_client` + `wintun.dll`) с GitHub — согласитесь.
3. Нажмите **«Вставить ссылку»** и вставьте ссылку `tt://…`, которую дал администратор сервера. Подойдёт и файл `.toml`.
4. Нажмите большую кнопку — готово. Внизу появятся внешний IP, время в сети и скорость.

| Первый запуск | Редактор сервера |
|---|---|
| ![](docs/first-run.png) | ![](docs/server-editor.png) |

Своего сервера нет? Его можно поднять на любом VPS по [инструкции TrustTunnel](https://github.com/TrustTunnel/TrustTunnel#quick-start).
Удобно управлять сервером и пользователями из веб-панели [TrustTunnel Panel](https://github.com/un1t-h/trusttunnel-panel).

## Возможности

- **Подключение одной кнопкой.** Состояние описано простыми словами: «Подключено», «Подключение…», «Трафик идёт мимо VPN».
- **Проверка, что VPN действительно работает.** Программа следит, что маршрут в интернет идёт через туннель, и показывает внешний IP.
  Если трафик идёт мимо, она об этом скажет. Перед подключением предупреждает, если включён другой VPN (AmneziaVPN, WireGuard и т. п.).
- **Исключения без ручной правки конфигов.** Отдельное окно открывается кнопкой под статусом:
  - готовые наборы — Claude / Anthropic, Discord, YouTube, Telegram, WhatsApp, Steam, Twitch, Spotify, российские сервисы (банки, Госуслуги, Яндекс, VK), все сайты .ru/.рф/.su;
  - **приложения**: для известных программ берётся готовый набор, для остальных клиент 20 секунд наблюдает, куда программа подключается,
    и предлагает эти домены и адреса. Официальный `trusttunnel_client` не умеет исключать процессы напрямую, поэтому приложение превращается в список адресов;
  - свои сайты, IP и подсети — добавить, вставить списком, удалить;
  - режим «всё через VPN, кроме…» или «через VPN только…». Изменения применяются переподключением одной кнопкой.
- **Запуск с Windows и сразу подключение.** Галочка «Запускать с Windows и сразу подключаться к этому серверу» на главном экране.
  Программа стартует при входе в систему: задача Планировщика без ограничения времени, работает и от батареи, с паузой 15 с, пока поднимается сеть.
  Затем сама подключается к выбранному серверу. Вместе со сценарием **«через VPN только Claude и Anthropic»** (окно «Исключения» → «Быстрая настройка»)
  Claude в браузере, приложение Claude и Claude Code работают сразу после включения компьютера, а остальной трафик идёт напрямую.
- **Соединение держится само.** Переподключение без ограничения числа попыток (пауза до минуты), мгновенная попытка при появлении сети,
  переподключение после сна. Сторож раз в 30 секунд проверяет, что сайт за туннелем действительно открывается (в режиме «только Claude» — claude.ai),
  и переподключает, если связь пропала, а процесс клиента ещё жив.
- **Разделение маршрутами, когда это возможно.** Если в режиме «через VPN только выбранное» всё выбранное известно по IP-адресам
  (Claude / Anthropic, Telegram, свои IP и подсети), в туннель заводятся только эти сети — как в WireGuard и AmneziaVPN.
  Остальной трафик туннеля не касается, поэтому zapret и GoodbyeDPI продолжают работать. IPv6-сети сервисов добавляются,
  только если включено «Пропускать IPv6 через VPN» — выключите его, если у сервера нет выхода в IPv6.
  Если выбран сервис без известных адресов (например, Spotify на облачных CDN), программа переходит на разделение по доменам.
  Какой способ сработает, видно прямо в окне «Исключения». Kill switch при разделении маршрутами не используется.
- **Надёжное разделение туннеля.** Клиент TrustTunnel на Windows не всегда сам находит физический адаптер для прямых соединений,
  и тогда в режиме «через VPN только выбранное» всё остальное не открывается ([TrustTunnelClient#56](https://github.com/TrustTunnel/TrustTunnelClient/issues/56)).
  Программа сама определяет адаптер (Ethernet или Wi-Fi, VPN-адаптеры пропускаются) и прописывает `bound_if`, а при смене сети переподключается с новым.
  Адаптер можно указать и вручную в редакторе сервера.
- **Локальные сети напрямую или через VPN.** Адреса 192.168.x.x, 10.x.x.x, 172.16–31.x.x можно пустить мимо VPN (роутер, принтер, NAS дома)
  или через VPN — к сетям за сервером, при этом своя домашняя сеть по желанию остаётся напрямую.
  На сервере нужно разрешить доступ клиентов к локальной сети (в [TrustTunnel Panel](https://github.com/un1t-h/trusttunnel-panel) — одним переключателем).
- **Совместимость с zapret и GoodbyeDPI.** Эти программы перехватывают пакеты на всех адаптерах, включая VPN, и подмешивают «фальшивые» пакеты.
  Внутри туннеля это ломает Discord, YouTube и другие сайты из их списков. На время подключения клиент приостанавливает zapret или GoodbyeDPI
  (службу или процесс), а после отключения запускает снова с прежними параметрами. При разделении по доменам это нужно и в режиме
  «через VPN только выбранное»: перехваченные пакеты на портах 80/443 zapret отправляет заново, Windows возвращает их в туннель,
  и сайты вне VPN не открываются. При разделении маршрутами zapret не трогается. Приостановку можно выключить в настройках.
- **Несколько серверов.** Импорт из ссылки `tt://`, файла `.toml`, буфера обмена (Ctrl+V) или перетаскиванием. Экспорт в ссылку `tt://` для телефона.
- **Все параметры клиента**: HTTP/2 или HTTP/3, anti-DPI, TLS-отпечаток, сертификат, режим маршрутизации и исключения, kill switch, DNS (DoH/DoT/DoQ), TUN или SOCKS5, MTU.
- **Трей**: значок меняет цвет по состоянию, из меню можно подключиться и переключить сервер.
- **Автопереподключение** при обрыве, подключение при запуске, автозапуск вместе с Windows, открытие ссылок `tt://` из браузера.
- **Безопасность**: пароли хранятся зашифрованными через Windows DPAPI. Конфиг с паролем пишется на диск только на время подключения.
  Отключение идёт через Ctrl+C, чтобы клиент сам вернул маршруты и DNS.
- **Журнал** подключения в окне (Ctrl+L) и в файле `%APPDATA%\TrustTunnelGUI\logs`.

## Сборка из исходников

Ничего устанавливать не нужно: используется компилятор C#, встроенный в Windows.

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1 -Test
```

Результат — `bin\TrustTunnelGUI.exe`. Флаг `-NoElevate` собирает версию без запроса UAC (для отладки интерфейса).
Релизы собираются автоматически через GitHub Actions при публикации тега `v*`.

## Удаление

```powershell
$env:TTGUI_UNINSTALL=1; irm https://raw.githubusercontent.com/un1t-h/trusttunnel-gui/main/install.ps1 | iex
```

## Устройство

| Файл | Назначение |
|---|---|
| `src/MainForm.cs` | главное окно, трей, импорт/экспорт, интеграция с Windows |
| `src/ProfileForm.cs`, `src/SettingsForm.cs` | редактор сервера, настройки |
| `src/Theme.cs`, `src/UiControls.cs` | темы и собственные элементы интерфейса |
| `src/VpnController.cs` | запуск `trusttunnel_client`, состояние, маршрут, остановка |
| `src/ClientInstaller.cs` | скачивание официального клиента и `wintun.dll` |
| `src/DeepLink.cs` | ссылки `tt://` по [спецификации](https://github.com/TrustTunnel/TrustTunnel/blob/master/DEEP_LINK.md) |
| `src/Toml.cs`, `src/ConfigBuilder.cs` | разбор и генерация `trusttunnel_client.toml` |
| `tests/SelfTest.cs` | самопроверка (`build.ps1 -Test`) |
